# Brand Commerce

Dự án e-commerce full-stack TypeScript.

## Công nghệ

- Frontend: Next.js, TypeScript, Tailwind CSS
- Backend: NestJS
- Database: PostgreSQL, Prisma
- Local infrastructure: Docker Compose, Mailpit
- Package manager: pnpm

## Cấu trúc

- apps: các ứng dụng frontend và backend
- packages: cấu hình và thư viện dùng chung
- infra: cấu hình hạ tầng local
- docs: tài liệu dự án

## Yêu cầu môi trường

- Node.js 26.x LTS
- pnpm theo trường packageManager trong package.json
- Docker Desktop
- Git
